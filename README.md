## ⚡ What I'm Building

### 📈 Hedge Trading Bot

An automated dual-asset trading strategy written in **MQL5**.

The goal isn't to predict the market.

It's to build a system capable of:

* Monitoring multiple instruments
* Detecting market imbalances
* Managing paired positions
* Executing predefined strategies
* Controlling risk programmatically
* Producing measurable, testable results

**Status:** `Active Development`
